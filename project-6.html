Vintage Volkswagen Beetle Modeling

Computer-Aided Design Siemens NX Automotive Design Surface Modeling GD&T

Overview

This project report details the process of creating a 3D model of a classic Volkswagen Beetle using Siemens NX. The design takes inspiration from the famous “Herbie the Love Bug” and includes iconic livery like racing stripes and number 98. The model was constructed from a spline curve wireframe using surfacing and edge blending techniques with G1/G2 continuity, Reflection analysis verified that its shape met all curvature and tangent continuity requirements.
