# Kill Web

An unofficial fan-made command game in the browser: find tracks, identify them, pair the right shooter. Nine missions, five pace levels, full arsenal from the start. Plays in landscape on desktop, tablet and phone.

## Legal

Unofficial fan project, made for a personal portfolio and never sold or monetized. It is not affiliated with, endorsed or sponsored by Anduril Industries, Inc. or any other company. Every unit, system and place name in the game is fictional. No company logos, imagery, documents or data are used: terrain, buildings, key art, unit models and sound are generated by code in this project. The Vanta Combine, the Kestrel Coast and every performance value are fictional game values; hangar notes describe real-world classes of systems and link to public reporting.

## Play locally

The game uses ES modules, so it needs a web server (opening `index.html` from disk will not work):

```
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository (files at the repository root).
2. Repository **Settings > Pages**: Source **Deploy from a branch**, branch **main**, folder **/ (root)**, Save.
3. After a minute the game is live at `https://<your-user>.github.io/<repo>/`.

Saves live in each player's browser (localStorage).

## Files

- `index.html`: the page and all styles
- `js/`: game code (simulation, 3D world, HUD, menus)
- `assets/`: terrain textures, height maps and building layouts for the nine missions
- 3D rendering uses three.js 0.160 from the jsDelivr CDN; fonts come from Google Fonts
